MG1 TRACKER – PWA PRO IPHONE

Pro instalaci na iPhone musí být aplikace dostupná na HTTPS adrese. Samotný HTML soubor nestačí.

Zveřejnění zdarma přes GitHub Pages:
1. Přihlas se na GitHub a vytvoř nový veřejný repozitář, např. mg1-tracker.
2. Nahraj do kořene repozitáře všechny soubory a složku z tohoto balíčku.
3. Otevři Settings > Pages.
4. V části Build and deployment vyber Deploy from a branch, větev main a složku /(root), pak Save.
5. Počkej, až se zobrazí zveřejněná adresa podobná https://TVUJ-UCET.github.io/mg1-tracker/
6. Na iPhonu otevři tuto adresu přímo v Safari.
7. Klepni na Sdílet > Přidat na plochu. Pokud je nabídka „Otevřít jako webovou aplikaci“, nech ji zapnutou a klepni na Přidat.

Data se ukládají lokálně v daném prohlížeči/aplikaci, nesynchronizují se automaticky mezi zařízeními. Pravidelně exportuj CSV jako zálohu.
